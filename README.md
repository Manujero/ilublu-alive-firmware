# ILUBLU ALIVE · actualizaciones por Wi-Fi

Aquí solo están los archivos que descarga el llavero ILUBLU ALIVE para actualizarse solo.
El código del firmware no está aquí.

- `manifest.json`: la última versión y de dónde bajarla. El llavero lo consulta al conectarse al Wi-Fi.
- `ilublito-alive-app-vX.Y.Z.bin`: el programa. Se instala sin borrar la partida.
- `eventos.json`: el calendario de fiestas (Halloween, Navidad...). Solo datos: fechas, tema, cartel y regalo.

No borres ni renombres este repositorio. Los llaveros que ya están en la calle buscan las
actualizaciones en esta dirección. Para cambiar de sitio, primero hay que publicar aquí una versión
que apunte a la dirección nueva y esperar a que los llaveros se actualicen.
